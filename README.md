# 🩺 Diabetes Prediction

A Machine Learning project to predict whether a patient has diabetes based on health parameters.

---

## 📌 Project Overview

This project uses a diabetes prediction dataset containing patient health records. The goal is to classify patients as **Diabetic** or **Non-Diabetic** using various health indicators.

---

## 📂 Dataset Features

| Feature | Description |
|---------|-------------|
| `gender` | Patient gender |
| `age` | Patient age |
| `hypertension` | Hypertension status (0/1) |
| `heart_disease` | Heart disease status (0/1) |
| `smoking_history` | Smoking history |
| `bmi` | Body Mass Index |
| `HbA1c_level` | Blood sugar level |
| `blood_glucose_level` | Blood glucose level |
| `diabetes` | 0 = No Diabetes, 1 = Diabetes |

---

## 🛠️ Tools & Libraries

- **Data Processing:** Pandas, NumPy, LabelEncoder, StandardScaler
- **Visualization:** Matplotlib, Seaborn
- **ML Models:** Scikit-Learn

---

## 🔍 Project Workflow

1. Data Loading and Exploration
2. Data Preprocessing — Label Encoding, StandardScaler
3. Exploratory Data Analysis
4. Train-Test Split — 80% train, 20% test
5. Model Training and Comparison
6. Evaluation — Accuracy, Classification Report, Confusion Matrix
